# Forge IDE

AI-powered code editor. No API key needed.

---

## Install (Windows)

1. Click **Code** > **Download ZIP** on this page
2. Extract the ZIP anywhere (Desktop, Downloads, etc.)
3. Open the `forge-ide` folder
4. Open the `installer` folder
5. Double-click **install.bat**
6. Wait for it to finish (installs Node.js + browser)
7. Done

**Launch:** Type `forge-ide` in terminal or use the desktop shortcut

---

## First Time

1. Open the IDE with `forge-ide in terminal`
2. A tutorial will appear — click through it
3. Open a project folder (File > Open Folder)
4. Type a task in the chat on the right side
5. A browser window will open — log into DeepSeek or Gemini (free)
6. The browser closes after login
7. Everything works silently from now on

---

## What You Can Do

- **"make a calculator"** — Creates a working calculator
- **"add a login page"** — Adds authentication to your project
- **"fix the bug on line 42"** — Reads code and fixes issues
- **"write tests for this"** — Generates test files
- **"deploy this to production"** — Runs build and deploy commands

## Troubleshooting

**"forge-ide is not recognized"**
- Open a new terminal window after install

**Browser doesn't open**
- Run `install.bat` again

**Nothing happens when I type a task**
- Make sure you logged into the AI in the browser window
